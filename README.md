# Rien's Cupcake Collector

Help Rien collect all 9 Prescripts, or "cupcakes," to appease the higher beings!

# How to play
Head to "https://christinelebxsci.github.io/riens-cupcake-collector/" where the game is hosted. The game's proportions load in correctly on Google Chrome and Microsoft Edge, while Firefox messes them up.

LEFT ARROW = Move left, must be hit constantly to maintain velocity

RIGHT ARROW = Move right, must be hit constantly to maintain velocity

UP ARROW = Jump
